# Volatility Spillover Analysis (GARCH Model)

## Overview
This project analyzes volatility dependence between MCX (commodity market) and Nifty 50 (equity market) using GARCH models.

## Dataset
- Daily data (2015–2025)
- Includes major events like COVID-19

## Methodology
- Stationarity Testing (ADF)
- ARCH Effect Testing
- GARCH, EGARCH, TGARCH Models
- Spillover Analysis

## Key Insights
- Strong volatility clustering observed
- Bidirectional spillovers present
- Equity → Commodity spillover stronger
- COVID increased volatility transmission by ~40–60%

## Tools Used
- EViews
- Time Series Econometrics
